- 供应商公司电话不在校验范围内

### 4. 会员等级功能
- 数据库 member 表新增 `level` 字段：SVIP / VIP / 普通会员（默认）
- 一号管理员（11xxx）注册后自动入会为 SVIP
- 二号/三号管理员（10xxx/01xxx）注册后自动入会为 VIP
- 会员表排序：管理员会员排前三行，等级从高到低
- 三个管理员本人的会员等级不可修改，其他会员等级可由管理员修改
- 前端会员等级用彩色标签显示（SVIP 红色、VIP 橙色、普通会员灰色）

### 5. 个人信息与头像功能
- 数据库 sys_user 表新增 `avatar`、`gender`、`age`、`address` 字段
- 新增 `/user/updateProfile` 接口，支持当前用户自行编辑个人信息
- 页面右上角新增圆形头像，点击跳转个人信息页
- UserInfo 页面支持头像上传（base64 存储）、性别选择、年龄输入
- 地址支持"省市区级联选择"和"手动输入"双模式切换
- 修改密码需旧密码验证 + 二次确认
- 员工编号、角色、会员等级不可修改

### 6. 员工注册流程改造
- 管理员新增员工只填写员工编号、工资、备注
- 姓名、密码、电话留空，等员工自行注册时填写
- 员工注册时查找已有记录并 UPDATE（非 INSERT）
- 注册成功后自动加入会员表

- 每页最多显示 10 条数据
- 使用 Element Plus 的 el-pagination 组件

- 数量和金额列添加单位显示（件 / 元）

### 9. 其他优化

- 创建时间列分两行显示（日期/时间），避免串行

## 二、开发中遇到的问题与解决方案

### 问题1：前端角色值不一致导致员工检查失败
- **问题描述**：前端将普通用户角色设为 `'2'`，但后端查询 `role = 0`，导致 `countEmployees()` 永远返回 0
- **解决方案**：统一前端所有普通用户角色为 `'0'`，涉及 Login.vue、Layout.vue、Employee.vue

### 问题2：注册表单角色与单选按钮脱节
- **问题描述**：角色单选按钮绑定 `form.role`，但注册代码使用 `regForm.role`（始终为 `'1'`），所有注册均以管理员身份进行
- **解决方案**：注册代码改用 `form.value.role`，删除 regForm 中独立的 role 字段

### 问题3：新增员工报错 "Column 'password' cannot be null"
- **问题描述**：管理员新增员工时不填密码，数据库 password 列 NOT NULL，INSERT 失败
- **解决方案**：后台判断 password 为 null 时自动设为空字符串 `""`

### 问题4：selectByPhone 返回多条导致 TooManyResultsException
- **问题描述**：旧测试数据和自动入会的管理员会员使用相同电话，MyBatis selectOne() 返回多条记录报错
- **解决方案**：SQL 加 `LIMIT 1` 兜底，同时修复重复数据

### 问题5：编辑员工时跨表电话误报
- **问题描述**：员工同时也是会员，编辑员工信息时系统提示"该电话号已在会员中使用"
- **解决方案**：UPDATE 操作只做本表去重，不跨表校验（同一人可同时是员工和会员）

### 问题6：新增员工 phone 被构造为 "+86|" 触发校验失败
- **问题描述**：前端 submitData.phone 拼接了区号 + `|` + 空号码 = `"+86|"`，后端校验失败
- **解决方案**：新增模式下 phone 和 password 直接设为 null，不做拼接

### 问题7：UserInfo 导入不存在的函数导致模块加载失败
- **问题描述**：从 `@/api/user` 导入了不存在的 `getMemberList`，Vue 组件加载崩溃
- **解决方案**：修正为从 `@/api/member` 导入，别名 `apiGetMemberList`

### 问题8：登录页 onMounted 未导入导致白屏
- **问题描述**：添加 `watch` 导入时移除了 `onMounted`，但模板中仍调用空的 `onMounted(() => {})`
- **解决方案**：删除无用的空 onMounted 调用
