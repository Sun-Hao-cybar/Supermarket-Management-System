## 二、开发中遇到的问题与解决方案

### 问题1：会员编辑报错 "Column 'member_no' cannot be null"
- **问题描述**：编辑会员信息时，即使会员编号字段显示正确，但保存时报错提示 member_no 不能为 null
- **解决方案**：修改 MemberMapper.xml 中的 update 语句，使用动态 SQL 的 <set> 和 <if> 标签，只更新非空字段，避免了将 null 值更新到数据库

### 问题2：ExcelUtil 调用参数顺序错误
- **问题描述**：编译时提示 ExcelUtil.exportExcel 方法参数不匹配
- **解决方案**：检查 ExcelUtil 源码，确认方法签名为 (headers, fieldNames, dataList)，修正了 MemberService 中的调用顺序

### 问题3：前端背景图片不显示
- **问题描述**：虽然设置了背景图片，但页面仍然是白色背景
- **解决方案**：确认图片已正确放置在 frontend/public/ 目录下，并调整了 CSS 样式确保背景正确显示

### 问题4：删除用户时外键约束错误
- **问题描述**：删除用户时，由于采购表中有外键关联，导致无法删除
- **解决方案**：修改数据库表结构，为外键添加 ON DELETE CASCADE，实现级联删除

### 问题5：SQL LIKE 语法错误
- **问题描述**：查询管理员时使用 like ?% 导致 SQL 语法错误
- **解决方案**：修改 MyBatis 映射文件，使用 CONCAT(#{prefix}, '%') 正确拼接通配符
