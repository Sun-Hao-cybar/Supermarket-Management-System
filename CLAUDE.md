# Supermarket-Management-System

## Project Overview

超市进销存管理系统 — Vue 3 + Spring Boot + MyBatis 全栈项目。

- **Frontend**: Vue 3 (Vite) + Element Plus, `frontend/`
- **Backend**: Spring Boot 4 + MyBatis, `backend/`
- **Database**: MySQL 8.0, `database/`
